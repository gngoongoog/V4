# BRAINTRADE V4 NEXT — واجهة ويندوز الجديدة

هذه **مرحلة تنفيذ عملية** لتصميم نافذة جديدة بـ HTML/CSS/Canvas JS داخل **Windows WinForms WebView2**، مبنية على الصورة الأصلية المعتمدة `REFERENCE_ORIGINAL.png`، وليست إعادة تلوين Slint.

## المكوّنات
- `ui/`: واجهة حقيقية تفاعلية (قائمة، بطاقات، أزرار، شارت شموع ومتوسطات وحجوم، Tabs، ثيمات داكن/دخاني/أبيض، فلاتر، تأكيدات).
- `WindowsShell/`: تطبيق Windows `BrainTrade.Next.exe` عبر .NET 8 وWebView2، يعمل مع **BrainTrade.exe القديم بنفس المجلد** ويحافظ على كل وظائف Core والصفحات الـ22 في واجهة V4 الأصلية.
- `REFERENCE_ORIGINAL.png`: الصورة المرجعية المتفق عليها، وليست Screenshot للتطبيق.
- `Build-Windows.ps1`: بناء تطبيق x64 وتضمين ملفات V4 الأصلية من مجلد توزيعه.

## الاستخدام كمعاينة تصميم
افتح `ui/index.html` محلياً من متصفح Edge أو Chrome. بيانات الأرقام والشارت **وهمية ومعلمة بأنها معاينة**، ولا تفتح صفقات حقيقية. في التطبيق Windows لا يعمل وضع المعاينة افتراضياً، وتظهر بيانات MT5 فقط عند حصول اتصال مؤكد بمحرك Rust المحلي.

## بناء تطبيق ويندوز
1. استخدم Windows 10/11 x64 وثبّت .NET 8 SDK وWebView2 Runtime (إن لم يكن موجوداً).
2. وفّر مجلد إصدار V4 الأصلي الذي يحتوي `BrainTrade.exe` و`runtime/`.
3. في PowerShell من جذر هذا المشروع:

```powershell
.\Build-Windows.ps1 -OriginalV4Folder "C:\Path\To\Original-V4-Portable"
```

4. شغّل `publish\BrainTrade.Next.exe`؛ يجلب بيانات `/v1/status` من Core، ويشغّل `BrainTrade.exe --core` من الملف الأصلي إذا لزم.
5. زر «واجهة التحكم الكاملة» يفتح تطبيق V4 الأصلي لجميع الصفحات والعمليات المتقدمة التي لم تُنقل بعد إلى هذه الواجهة.

## قيود واضحة
- **ليست نسخة 1:1 مؤكدة بصرياً بعد**: تم تنفيذ بنية الألوان والكتل الأساسية بدقة مرجعية، لكن لم أختبر الرندر الأصلي على شاشة Windows حتى الآن.
- التفاعل في المعاينة حقيقي داخل واجهة الويب، **أما الإشارات والأرقام المرسومة فهي أمثلة فقط**. في الوضع الحقيقي لا يتم اختلاق نسب نجاح أو تعلم أو سرعة تنفيذ.
- `START` / `STOP` فقط متصلان بـCore هنا، والتحقق من REAL ودقة الحساب يكون في العميل والمحرك. بقية الإعدادات المتقدمة تفتح تطبيق V4 الأصلي، فلا توجد أزرار تدعي التحكم بلا ربط.
- يحتاج البناء إلى التحقق على Windows من مسار `ipc.key` وفق إعداد Rust `directories::ProjectDirs` ومن توزيع مكتبات WebView2/DPAPI، ثم اختبارات MT5 Demo قبل الاعتماد.
- لا تغيّر كلمة السر أو مفتاح Core بأي كود JavaScript: المفتاح يُفك عبر Windows DPAPI داخل C#، ولا يصل إلى صفحة الواجهة.
