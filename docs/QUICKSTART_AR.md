# BRAINTRADE OS 0.4.0 Preview — التشغيل على Windows

## أول تشغيل

1. فك ضغط الحزمة كاملة إلى مجلد مثل `C:\BrainTrade-0.4.0`، ولا تشغّل التطبيق من داخل ZIP.
2. إذا كانت نسخة قديمة تعمل، افتحها واضغط **خروج كامل** قبل فتح الجديدة.
3. افتح **BrainTrade.exe**. هذا هو ملف التشغيل الوحيد الذي تحتاجه؛ لا تحتاج تثبيت Python أو Rust أو فتح أوامر.
4. من **الإعدادات → اختيار الملف** اختر `terminal64.exe` الخاص بمنصة وسيطك، مثل `C:\Program Files\MetaTrader 5\terminal64.exe`.
5. ضع اسم الرمز كما يظهر في MT5، مثل `XAUUSD` أو `XAUUSDm`، ثم **حفظ الإعدادات وإعادة الاتصال**.
6. سجّل دخول حسابك داخل MT5 واحفظه أول مرة. التطبيق يحاول تشغيل المنصة والاتصال بها حتى إذا كانت مغلقة؛ MT5 نفسه يجب أن يكون مثبتاً.
7. بعد ظهور الحساب والرصيد، اضغط **تشغيل النظام START** لبدء المحاكاة. **STOP** يمنع دخول محاكاة جديد ويسحب أرقام الفرص فوراً؛ مخارج المحاكاة المفتوحة تستمر مع البيانات.

إغلاق النافذة يبقي Core والجسر شغالين. زر **خروج كامل** يوقف التطبيق والجسر؛ لا يغلق صفقات الوسيط ولا يغلق منصة MT5 نفسها.

| الصفحة | ما تعرضه |
| --- | --- |
| الرئيسية | الحساب، الرصيد، حقوق الحساب، صافي اليوم، اتصال MT5 والصفقات الموجودة |

| خريطة العقول والمناطق | المناطق والقمم والقيعان، زخم الفريمات والتباعد، Gann، DOM، نشاط ticks والجلسة |

الصفحات التي تحتاج بيانات تعرض حالة الانتظار بوضوح؛ عدم ظهور فرصة لا يعني عطلًا. لا يُختلق Entry أو DOM عند غياب البيانات. سجل الفرص تاريخي وليس توصية حالية.

## Telegram — أضفه لاحقاً من الإعدادات

ضع Bot Token، ومعرف المستخدم الرقمي User ID، ونفسه في Private Chat ID، ثم فعّل Telegram واحفظ. احتفظ بالتوكن محلياً؛ لا تحتاج إرساله في المحادثة. يُحفظ باستخدام Windows DPAPI.

الأوامر: `/status`، `/report`، `/positions`، `/health`، `/brains`، `/opportunities`، `/paper`، `/news`، `/backtest`، `/help`.

البوت يجيب على الاستعلامات الخاصة المسموح بها. يلزم اتصال إنترنت؛ التحقق بتوكنك الفعلي يتم على جهازك.

## التعلم والبيانات

تُجمع features من شموع مكتملة وتنتظر نتائج 5/15/30 دقيقة الدقيقة. صدّر dataset من الصفحة وشغّل `Source/scripts/train_linear_baseline.py` في بيئة تطوير إن أردت تدريب نموذج؛ لا يوجد تدريب تلقائي داخل التطبيق. استورد JSON ثم افحص الدليل الزمني قبل تسجيل أهلية المراجعة. التوقعات للمراقبة وقياس النتائج فقط.

## التحديث والنسخة الاحتياطية

قبل تبديل النسخة، استخدم **نسخة احتياطية** ثم **خروج كامل**. ضع النسخة الجديدة في مجلد منفصل. إعداداتك وسجلاتك محفوظة في بيانات تطبيق المستخدم وليست بجانب EXE، وتُقرأ عند فتح النسخة الجديدة. لا تحذف مجلد بيانات التطبيق لحل مشكلة؛ احتفظ به وبالنسخة الاحتياطية.

النسخة الاحتياطية تستبعد Telegram token. الاستعادة الكاملة بزر داخل التطبيق لم تُنفذ بعد.

## حدود الإصدار والتجربة

هذه حزمة تحليل وبحث ومحاكاة: **لا تفتح أو تعدل أو تغلق صفقات MT5**. Legacy Meta يقود Shadow؛ بقية العقول والنماذج بحثية. لا يوجد Champion مفعّل أو ترقية تلقائية.

DOM هو عمق الوسيط إذا توفر، ونشاط ticks ليس حجم تداول عالمي. الاختبارات الآلية لا تثبت الربحية. التحقق النهائي من منصة وسيطك والتاريخ وDOM وTelegram يحتاج اللابتوب؛ إذا ظهرت مشكلة احتفظ برسالة الخطأ ولقطة الصفحة ووقت حدوثها.
