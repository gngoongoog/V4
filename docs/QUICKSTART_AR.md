# BRAINTRADE OS 0.3.0 — دليل المصدر والميزات

هذه نسخة كود المصدر؛ تجهيز حزمة Windows مؤجل بطلبك. آخر حزمة جاهزة سُلّمت هي 0.2.0.
خطوات التحديث أدناه للحزمة الجاهزة عند تجهيزها لاحقاً.

## التحديث

1. افتح النسخة القديمة واضغط **خروج كامل**. إغلاق النافذة وحده يبقي المحرك شغالاً.
2. فك الحزمة الجديدة كاملة في مجلد مستقل، ثم افتح **BrainTrade.exe** فقط.
3. إعدادات MT5 السابقة تبقى محفوظة لنفس مستخدم Windows. لا تحتاج تثبيت Python أو Rust.
4. افتح **العقول والتحليل** واضغط **تشغيل النظام**. المحاكاة تدخل عند تحقق الشروط.

إذا ظهرت رسالة عن محرك قديم، ارجع للنسخة القديمة واختر خروج كامل ثم افتح الجديدة.
بعد حفظ إعدادات الجديدة استخدمها؛ النسخة القديمة لا تفهم حقول المخاطرة الجديدة.

## مسار MT5

الإعدادات ← اختيار الملف ← اختر `terminal64.exe` من مجلد منصة وسيطك.
مثال: `C:\Program Files\MetaTrader 5\terminal64.exe`؛ المسار يختلف حسب الوسيط.
سجّل الدخول أول مرة داخل MT5. اكتب الرمز كما عند وسيطك، مثل XAUUSDm، ثم حفظ
الإعدادات وإعادة الاتصال. البرنامج يحاول فتح MT5 إذا كان مغلقاً.

## الصفحات الجديدة

**العقول والتحليل:** اتجاه دقيقة/خمس دقائق/ربع ساعة، زخم، اختراق 20 شمعة،
والقرار الرئيسي مع سبب الانتظار أو الدخول الافتراضي. هذه قواعد حسابية وليست
نماذج تعلم آلي مدربة؛ قوة الدليل ليست نسبة نجاح.

**المحاكاة:** صفقات افتراضية مستقلة تماماً عن رصيد MT5 مع حفظ حالتها ونتائجها.
زر التصدير يخرج الشموع والقرارات وسجل المحاكاة بصيغة JSONL؛ المسار يظهر أسفل الواجهة.

**المخاطرة:** إعدادات صفقات المحاكاة الجديدة. الافتراضات: مخاطرة 0.25% للصفقة،
خسارة يومية 2%، تراجع من القمة 5%، سبريد أقصى 0.25 ATR، وسقف لوت 0.10.
العمولة الافتراضية 7 من عملة الحساب لكل لوت ذهاباً وإياباً: **عدّلها حسب وسيطك**؛
ليست مكتشفة تلقائياً. الانزلاق المفترض حركتا سعر دنيا لكل جانب، ويمكن تعديله.
SL=1.5 ATR، الهدف ضعف مسافة SL، وخروج زمني بعد 30 دقيقة. السواب غير محسوب.
حساب المخاطرة تقريبي بقيمة tick من الوسيط، وليس فحص هامش أو تنفيذاً فعلياً.
الحد اليومي يتجدد بتوقيت بغداد، وقفل التراجع يبقى بعد بلوغه. تغيير الإعدادات
لا يمسح النتائج أو يحرر القفل؛ لا يوجد زر تصفير تجربة في هذه المرحلة.

## ظهور WAIT / انتظار

قد يعني عدم اتفاق الفريمات، ارتفاع السبريد، وجود صفقات أو أوامر MT5، لوت أدنى
أكبر من الميزانية، أو بيانات قديمة. نحتاج 100 شمعة مكتملة و30 شمعة أخيرة متتالية
لكل فريم. بعد عطلة السوق قد يتطلب شرط M15 سبع ساعات ونصف من الشموع الجديدة.
إذا السوق مغلق قد يظهر رصيد الحساب بينما يبقى التحليل بانتظار السعر. لا نولّد بيانات بديلة.

## التشغيل والإيقاف

تشغيل النظام يسمح بمداخل افتراضية. إيقاف النظام يمنع مداخل جديدة ويترك مخارج
المحاكاة تعمل على الأسعار المرصودة أثناء تشغيل المحرك. إغلاق الواجهة يبقي
المحرك شغالاً؛ إعادة تشغيل المحرك تبدأ بحالة متوقفة مع حفظ المحاكاة السابقة.
الخروج الكامل يوقف البرنامج والجسر ولا يغلق MT5 أو صفقاتك.
عند انقطاع السعر لا يفترض البرنامج حصول SL/TP داخل الفترة المفقودة؛ يستخدم
أول سعر عائد ويعلّم الصفقة بأنها متأثرة بانقطاع. نتائجها ليست تجربة مكتملة الرصد.

**هذه النسخة لا تفتح أو تعدل أو تغلق صفقات MT5، ولا تدير حمايتها.**

## Telegram لاحقاً

أدخل التوكن السري للبوت محلياً مع User ID الرقمي وPrivate Chat ID الرقمي
(نفس معرفك في الخاص). @اسم البوت لا يكفي. لا حاجة لإرسال التوكن هنا.
ترك التوكن فارغاً يحافظ على المحفوظ، ويخزن مشفراً عبر Windows DPAPI.
بعد التفعيل والحفظ افتح محادثة البوت واضغط Start.
الأوامر: /status /report /positions /health /brains /paper /news /backtest /help.
/news للأخبار المحفوظة، و/backtest لآخر نتيجة اختبار تاريخي.
/report لحساب MT5؛ /paper للمحاكاة منفصلة. البوت للاستعلام الخاص فقط.
التسليم بتوكن حقيقي لم يُختبر بعد.

## النسخة الاحتياطية

زر نسخة احتياطية يحفظ الإعدادات وقاعدة البيانات مع الأحداث والشموع والقرارات
وحالة المحاكاة. يستبعد التوكن. استعادة شاملة بواجهة المستخدم والتعلم الآلي
مراحل لاحقة. الصادرات تحتوي هوية الحساب؛ شاركها عند الحاجة فقط.


## الاختبار التاريخي

افتح صفحة الاختبار واختر Meta أو CES، تاريخ البداية والنهاية UTC (النهاية غير مشمولة، حتى 30 يوماً)، رأس المال الافتراضي والسبريد. اضغط STOP قبل جلب التاريخ وانتظر إغلاق الصفقة الافتراضية إن وجدت. تُستخدم إعدادات المخاطرة المحفوظة لحظة بدء الجلب.

بعد اكتماله يمكنك فتح النتيجة أو تصدير تقرير HTML مع منحنى الرصيد وملفات CSV/JSON. إعادة الاختبار تستخدم نفس البيانات والافتراضات دون اتصال. زر تجربة الاستراتيجية المختارة يغيّر الاستراتيجية فقط على بيانات النتيجة المحددة؛ لا يغيّر رأس المال أو السبريد بحسب حقول الجلب. كل تجربة تحفظ منفصلة.

CES هنا للاختبار التاريخي؛ المحاكاة المباشرة تبقى Meta. يستخدم حجم ticks ودخول الافتتاح التالي؛ لا تتوقع تطابق أرقام TradingView. شرح المعادلات والحدود في BACKTEST.md.

## الأخبار الرسمية

صفحة مستقلة للفدرالي الأمريكي والمركزي الأوروبي، تحدث كل خمس دقائق، مع تفعيل/إيقاف التحديث وفتح الخبر من مصدره. يظهر وقت النشر UTC وآخر تحديث ناجح لكل مصدر. إذا فشل الاتصال تبقى الأخبار المحفوظة وتظهر حالتها. هذه عناوين منشورة؛ ليست تقويماً للأحداث ولا توصية تداول.
