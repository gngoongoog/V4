# BRAINTRADE V25 / G3-B — سجل تداول MT5 الحقيقي مع تصفح الصفحات

## وظيفة الواجهة
- تدعم صفحة Trade Journal اختيار عرض 25 أو 50 أو 100 مركز مع السابق/التالي وتحديث يدوي.
- يعرض كل مركز Position ID، الرمز، اتجاه الصفقة، اللوت، نتيجة تسوية Deals، وصافي الربح بعد العمولة والسواب والرسوم **فقط** عند توفر جميع مكونات الإثبات.
- يوفر زر التفاصيل توقيت فتح المركز والعقل وسبب القرار واللوت المفتوح والمغلق والعمولة والسواب والرسوم. لا يجري أي عملية تداول أو إغلاق.
- التخزين والقراءة تابعان لـRust Core، بما في ذلك السجل المتبقي بعد إعادة تشغيل Core. عند انقطاع حساب MT5 أو عدم مطابقته تُخفى التقارير المالية حتى يعود الاتصال الصحيح.

## الواجهة التقنية والأمان
- أضيف أمر Tauri read_trade_history يقبل عددي offset وlimit فقط (0..1,000,000 و1..100). يرسل POST ثابتاً إلى /v1/execution/trades لغرض **قراءة التاريخ فقط**؛ لا يستطيع Frontend تحديد URL أو طريقة اتصال جديدة.
- أضيف مفتاح context صريح في استجابة السجل من Core؛ يُتحقق منه إلى جانب سياق الحساب المربوط، login/server/currency والرمز ووضع Demo/REAL.
- لا يتم اعتماد رد قديم بعد تغيير صفحة، رقم الحساب، الرمز، نوع الحساب، أو رقم الصفحة. أزرار الصفحات لا تتجاوز حدود Core.
- الاختبارات الآلية تغطي 73 مركزاً عبر صفحات منفصلة، رسوم ناقصة، تبديل Demo/REAL، سياق قديم، اسم رمز مختلف، أو offset/limit غير صالح.

## معيار إغلاق G3-B
نجاح npm test + TypeScript/Vite وResearch وWindows وPortable من Commit واحد. اختبار MT5 Demo على ويندوز يشمل فتح سجل من أكثر من 50 مركزاً وتبديل الصفحات ثم تبديل الحساب. لا يدّعي CI تنفيذ وسيط حقيقي.

هذا جزء مستقل من بوابة G3 وليس إصلاحاً جديداً متكرراً من G2. لا تغيير على main أو V24.
