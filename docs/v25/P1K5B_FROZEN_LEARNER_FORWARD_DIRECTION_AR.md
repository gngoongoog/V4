# V25 — P1-K5B: Frozen Sniper Learner future directional markout (foundation)

التاريخ: 24 أكتوبر 2026. Branch: `feature/v25-p1k5b-sniper-forward-direction-audit-20261024`, فوق P1-K5A / PR #139.

هذه الخطوة تكمل **تدقيق الاتجاه للمستقبل في نموذج Learner المجمّد فقط**، ولا تمنح صلاحية تداول أو اعتماد OOS مستقل وربحية.

## العقد

- يبدأ التقييم على MT5 Demo مقيد بنفس هوية الحساب والرمز، بعد تجميد السياسة ومضي Warmup الفعلي (2.1s). تُستخدم فقط أسعار المستقبل المقبولة من Native/Poll وفي السلسلة نفسها.
- تُفتح فرصة واحدة `Pending` عندما تصبح إشارة **النموذج المجمّد** صالحة. لا يوجد نوافذ تقييم متداخلة؛ يجب وصول سعر Broker آخر أصلي بعد **5,000ms على الأقل** لإنضاج نتيجة تلك الفرصة. لا تستخدم إشارة التدريب نفسها كحقيقة مستقبلية.
- التصنيف: اتجاه مطابق / معاكس / سعر شبه ثابت، اعتماداً على فرق Midquote وحجم tick. **هذا ليس سعر تنفيذ قابل للتحقق**؛ لا يُحتسب Spread أو Commission أو Slippage أو Margin أو Stop/TP أو Rejects أو Partial fills.
- عند فقد Native أو قفزة وقت الوسيط أو تغير Native/Poll أو وصول لقطة تسوية كاملة خارج Pulse، تُحذف الفرصة غير المنتهية من عينات النجاح والخسارة وتُعرض في عداد منفصل. إعادة ربط الحساب/تعديل المعلمات/STOP لا يستطيع إكمال فراغ بيانات.
- نسبة مطابقة الاتجاه لا تعرض إلا بعد 100 فرصة ناضجة على الأقل، وتبقى **وصفية لا احتمالية ربح ولا نتيجة إحصائية مستقلة**؛ لا ترقية تلقائية للعقل ولا أمر MT5.
- تُعاد النتائج إلى UI من تقرير P1-K3 نفسه في `forward_direction_audit` مع هوية الحساب الموجودة أصلاً. لا تظهر العينة للحساب الأجنبي/REAL أو في معاينة غير حقيقية.

## الاختبارات والقيود

- Rust: اختبارات عدم حساب نتيجة قبل 5 ثوان، منع التداخل، تصفية السعر التالف، إسقاط السيناريو غير المتصل، وحالات حسابات Demo / REAL الموجودة سابقاً.
- React: عدم عرض أي Fraction غير موثقة أو ادعاء PnL، وشروط التسجيل داخل واجهة Sniper.
- GitHub CI الكامل للشيفرة ذات SHA نفسه لازم ينجح قبل اعتماد المرحلة.
- `independent_oos=false` لأسباب موضوعية: لا شهادة فصل تدريب/اختبار مع عينات Broker كافية، ولا Dataset طويل متعدد الجلسات، ولا embargo/audit كافٍ للأنظمة المتكيفة. هذه خطوة تأسيسية في اتجاه P1-K5B وليست اكتماله.
- Windows click-through وMT5 Demo/MetaEditor ومطابقة Execution الحقيقي ما زالت تتطلب جهازاً فعلياً وسوقاً ووسيطاً.

## التالي

فصل نموذجي زمني durable مع إثبات Dataset/Window provenance، ضبط حصر العينات غير المتداخلة، ومقارنة baseline بعد جمع سجل تيكات متصل مرصود مع تكاليف الوسيط. لا يُعتبر قياس اتجاه منتصف السعر دليلاً أن الاستراتيجية مربحة.
