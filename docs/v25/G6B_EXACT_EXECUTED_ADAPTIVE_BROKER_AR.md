# BRAINTRADE V25 — G6-B | إثبات نتائج Adaptive المنفذة على MT5 Demo دون ادعاء مقارنة Broker ثنائية

## سبب المرحلة
G6-A تسجل دراسة Frozen/Adaptive على أسعار Demo المستقبلية بشكل ورقي، وتعترف بأن ذراع Frozen لا ينفذ صفقة في الوسيط. لكي نعرف ما إذا كانت أي نتائج Adaptive منفذة فعلياً قد حدثت بعد التسجيل، نحتاج ربطاً صارماً بين (1) قرار Adaptive في نفس النسخة المجمدة، (2) أمر فتح Broker الدائم، (3) رقم Deal الذي أكده MT5، (4) جميع سجلات الدخول والخروج من broker_deals، (5) صف تعلم Demo الذي جمع تكاليف التنفيذ الحقيقية.

## تدقيق G6-B الجديد
الملف: scripts/audit_v25_g6b_executed_demo_arm.py، يستخدم نفس Manifest المسجل مسبقاً في G6-A.

يشترط:
- تطابق تاريخ التسجيل/المهلة وبصمة استراتيجية Frozen والسياق كما يتحقق G6-A.
- ارتباط أمر الفتح برقم command_id الأصلي، وهوية الحساب ووضع Expert، وزمن بعد قرار Adaptive المحفوظ، ومفتاح الإشارة واتجاهها ورقم الشمعة نفسه.
- مقارنة open_deal مع رقم Deal المؤكد في رد MT5، وبروتوكول الجهاز الذي يمنع اعتبار مجرد تأكيد إرسال بمثابة نتيجة مغلقة.
- التحقق المباشر من جداول broker_deals وأن الدخول موجود، وحجم الخروج يساوي الدخول، ولا توجد Netting reversal غامضة، وأن آخر إغلاق يعود إلى نفس timestamp المحفوظ.
- إعادة جمع كل profit/commission/swap/fee من صفقات MT5 الأصلية ومقارنتها بصف تعلم النظام؛ لا تُستبدل القيم المفقودة بالصفر. يتأكد أيضاً من risk_money وR وreward_v2.
- منع تكرار نفس position_id حتى لو نُسب إلى أكثر من source، ومنع خلط حساب آخر أو أمر مُنشأ قبل فترة القياس.
- إخراج عدد المراكز المؤهلة، أسباب الاستبعاد، صافي Adaptive المنفذ والمغلق بحسب الوسيط، صافي/لوت، تكلفة ومعدل فوز وصفي. لا يُعرض مجموع إن لم توجد أدلة.

## ضمان عدم اختلاق تحسن
**المخرجات الثابتة مهما كانت نتائج الذهب:**
- frozen_executed_broker_pnl = null
- paired_executed_broker_delta = null
- broker_fills_for_frozen_comparator = 0
- independent_oos = false
- automatic_model_promotion = false
- live_execution_authorized = false

يُظهر التقرير نتيجة **ذراع Adaptive المنفذة فقط** إذا وُجدت إثباتات Broker Demo فعلية. لا يجوز طرح أرباح ذراع ورقية من منفذة والقول إن ذلك تحسن Broker، ولا يجوز عد سجلات تدريب عدة عقول باعتبارها صفقات مستقلة.

## طريقة التشغيل
بعد تسجيل دراسة G6-A وقبل أن تتغير البيانات، وعند توافر صفقات MT5 Demo مغلقة فعلياً:

```bash
python scripts/audit_v25_g6b_executed_demo_arm.py --db "PATH_TO_CORE.sqlite" --manifest "g6a-study-manifest.json" --output "g6b-booked-demo.json"
```

الأداة تقرأ SQLite قراءة فقط، ولا تفتح أوامر أو تقرر أحجام لوت، وتعرض أسباب رفض أي رقم غير منسوب بدقة. لا تشارك ملف SQLite مع جهات غير موثوقة.
