# BRAINTRADE Enterprise V25 — G3-A | عرض تقارير MT5 الحقيقية في لوحة Windows

## الانتقال من G2 إلى G3
G2-M اجتازت Research وPortable؛ الفحص Windows العام ما زال منفصلاً عن إثبات MT5 Demo الحقيقي. لا نضيف إصلاحات G2 جزئية بلا سبب CI واضح. يبدأ هذا الفرع مرحلة G3 لأداء الواجهة وربط جميع عناصرها بمصادر فعلية.

## أُنجز هنا
- استُبدل القسم الثابت «أحدث الصفقات» في Dashboard بقراءة من `/v1/execution/trades`؛ تبقى حالات OPEN وPARTIAL وCLOSED وأحجام اللوت وطبيعة الإثبات مأخوذة من سجل Core.
- يعرض صافي الأرباح فقط حين يؤكد `booked_cost_evidence=BROKER_COMPONENTS_VERIFIED` أن السجل يحتوي رسوم profit والعمولة والسواب والـfee، خلاف ذلك يعرض «صافي غير موثّق».
- استُبدلت مقاييس جودة التنفيذ التي كانت كلها شرطات في الوضع الحقيقي ببيانات `/v1/execution/quality` الموثقة: MT5 Send P95 وQueue→Send P95 وعدد المرفوضات والمعلقات.
- تُقرأ تقارير هوية الربط `/v1/execution` والتداول والجودة كمجموعة واحدة من Tauri IPC. عند تغير حساب MT5 أو وضع Demo/REAL أو الصفحة أو قدم القراءة لا تُعرض نتائج الحساب السابق.
- الأرقام الوهمية تبقى حصراً في Design Preview مع وسم DEMONSTRATION ONLY. لا توجد أي أوامر تنفيذ جديدة أو تعديل على مخاطر التداول من داخل لوحتي القراءة.
- أضيف CSS ملائم للسطح الضيق واختبار TypeScript/JSX لحالات تبديل الحساب، وتلف الرسوم، وحداثة البيانات، والأرقام المستعرضة.

## معيار قبول G3-A
1. نجاح `npm --prefix apps/terminal test` و`npm --prefix apps/terminal run build` وResearch للـSHA النهائي.
2. نجاح Windows وPortable لنفس الـSHA؛ وتجربة بصرية حقيقية على تطبيق Windows عندما يتوفر.
3. اختبار مصدر MT5 Demo الحقيقي مطلوب قبل اعتبار دورة التداول مثبتة، لكنه لا يوقف إصلاح ربط واجهة G3.

لا تعديل على main ولا مرجع V24. الفرع مستقل ومسودة PR #166 فوق G2-M #165.
