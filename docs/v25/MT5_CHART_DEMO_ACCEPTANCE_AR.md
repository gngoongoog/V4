# اختبار شارت BRAINTRADE V25 على حساب MT5 تجريبي — قراءة فقط

**الحالة:** أداة فحص من دون أي أمر تداول أو إغلاق أو تعديل مركز. هذا اختبار مصدر الشموع، وليس إثباتاً أن تنفيذ الصفقات أو اتصال Rust Core قد نجحا.

## المتطلبات

- جهاز Windows يعمل عليه برنامج MetaTrader 5، وحساب **Demo** متصل بالفعل.
- اسم رمز الذهب مطابق حرفياً لاسم الوسيط، مثل \`XAUUSD\` أو \`XAUUSDm\`. لا تغيّر الأداة الرمز أو الحساب.
- Python وحزمة MetaTrader5: \`py -3 -m pip install MetaTrader5\`.
- تشغيل PowerShell من مجلد مصدر المشروع (الذي يحتوي \`scripts\`).

## الفحص

\`\`\`powershell
py -3 scripts/check_mt5_chart_readonly.py --symbol XAUUSD
\`\`\`

لتشترط شموعاً حديثة وسعراً حديثاً معاً:

\`\`\`powershell
py -3 scripts/check_mt5_chart_readonly.py --symbol XAUUSD --require-fresh
\`\`\`

إذا كان رمز الوسيط مختلفاً، بدّله **كما هو حرفياً** في الأمر. يخرج الفحص بنتيجة JSON ولا يطبع رقم الحساب. يمكن حفظ النتيجة محلياً هكذا:

\`\`\`powershell
py -3 scripts/check_mt5_chart_readonly.py --symbol XAUUSD > chart_demo_report.json
\`\`\`

## فهم النتائج

- \`DEMO_FEED_RECENT\`: حساب تجريبي ثابت أثناء الاختبار، وسعر Bid/Ask حديث، و180 شمعة مغلقة وسليمة لكل واحد من الفريمات M1/M5/M15/M30/H1/H4/D1، وتواريخ الإغلاق ضمن النطاق المقبول.
- \`DEMO_HISTORY_ONLY_OR_STALE\`: تاريخ الشموع سليم لكن هناك أسعار أو شموع غير حديثة. قد يحصل عند إغلاق السوق أو تأخر الوسيط؛ **ليس** قبولاً للتغذية الحية.
- \`DEMO_HISTORY_INCOMPLETE\`: بيانات إطار زمني أو أكثر ناقصة أو غير صالحة. راجع \`frames\` لمعرفة أيها فشل ولماذا.
- \`DEMO_ACCOUNT_REQUIRED\`: توقف مبكر لأنه ليس حساب Demo.
- \`ACCOUNT_SWITCHED_DURING_READ\`: تغيّرت هوية الحساب أثناء الجمع؛ جميع النتائج غير صالحة للاعتماد.
- \`EXACT_BROKER_SYMBOL_NOT_FOUND\`: تحقق من اسم الرمز في Market Watch.

## نطاق قبول هذه الخطوة

هذه الأداة تتصل بواجهة \`MetaTrader5\` مباشرة على الجهاز نفسه، وتستعمل عمليات قراءة حساب وسعر وشموع فقط. لا تستدعي \`order_send\` ولا تمرر أوامر إلى BRAINTRADE.

**ما زال مطلوباً لفحص النظام بالكامل:** تشغيل تطبيق Tauri بجانب MT5 Demo، التأكد أن حالة Gateway/EA ليست WAITING، فتح شارت M1 وM5 والفريمات الأخرى، مطابقة الأسعار والشموع مع نافذة MT5، مراقبة آخر شمعة مغلقة عندما تتغير، تجربة التكبير والسحب والخروج الكامل. لا تستخدم حساباً حقيقياً لهذا الاختبار.
