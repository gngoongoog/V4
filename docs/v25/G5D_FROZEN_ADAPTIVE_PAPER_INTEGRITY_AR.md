# BRAINTRADE V25 — G5-D | تدقيق Frozen مقابل Adaptive (Paper فقط)

## نطاق المرحلة
G5-C أصلحت إحصاءات Forward Learning. G5-D تستخدم بيانات التجربة المستقبلية الموجودة أصلاً في Rust من frozen_coordinator وcoordinator_paper، ولا تنشئ صفقة أو تشغّل تعلّماً.

المصدر الجديد: scripts/audit_v25_g5d_frozen_pairs.py، الاختبارات: tests/test_v25_g5d_frozen_pairs.py.

## شروط قبول الزوج
1. اختيار Frozen run_id واحد مثبت Expert مع weights_frozen=true، broker_permission=false، ووقت تجميد سابق لكل قرار.
2. وجود قرارين قبل اكتمال النتيجة من نفس الشمعة المكتملة حديثاً، وبفارق زمني <= 3 ثوان من السعر الملتقط للزوج، بلا وقت خروج مستقبلي.
3. مطابقة مفاتيح الإشارة والاتجاه من القرار المجمّد مع ذراعي الورقة، وإثبات ready للطرفين.
4. مصدر الأسعار المحدد MT5 Demo sampled BID/ASK، مع عدم وجود order_send. لا قبول لادعاء fill من الوسيط داخل النتيجة الورقية.
5. عقد تقديري PASS، لوت 0.01، spread غير معكوس، وفجوة سعر لكل ذراع <= 15 ثانية. رفض التغطية المفقودة والرايات المتناقضة.
6. إعادة حساب الربح النظري gross من حركة السعر والتكة والانزلاق وقيمة التكة واللوت، وحساب العمولة، والتحقق من net وnet_per_lot؛ رفض أي أرقام ناقصة أو مزورة.
7. تجميع الأزواج المؤهلة تحت هوية الحساب نفسها فقط. تسجيل أسباب الاستبعاد، وعدم الخلط مع بيانات REAL أو حسابات أخرى.

## المعنى الفعلي للنتيجة
يحسِب التقرير متوسط فرق صافي الربح **الورقي** لكل لوت (Adaptive minus Frozen). يعرض فاصل ثقة وصفي 95% بإعادة سحب مجموعات الأيام بطريقة محددة البذرة فقط عندما توجد 30 عينة مؤهلة على الأقل موزعة على 5 أيام UTC على الأقل.

كل تقرير يثبت:
- broker_pnl = null و broker_win_rate = null.
- independent_oos = false لأن قفل بيانات تدريب Adaptive قبل الدراسة غير مثبت بشكل مستقل.
- model_promotion_allowed = false و live_gate_pass = false، بلا استثناء.
- source = sampled Demo quote estimates؛ النتائج ليست MT5 broker fills ولا ضمانات لأي تحسين.

حتى لو كان متوسط Adaptive أفضل، قد تفوّت أسعار العينات المتقطعة ضرب وقف الخسارة أو الهدف، ولا تمثل التنفيذ الفعلي والانزلاق الحقيقي والـswap وقواعد المخاطر. ولا يجعل عدد الأيام عينات السوق مستقلة إحصائياً.

## التشغيل على جهاز المستخدم بعد وجود عينة Demo حقيقية
شغّل من جذر المشروع مع تحديد قاعدة Core SQLite الحالية (للـREAD ONLY) ومعرّف Frozen run الحقيقي:

python scripts/audit_v25_g5d_frozen_pairs.py --db "PATH_TO_CORE_DB.sqlite" --run-id "EXACT_RUN_ID" --output "g5d-paper-audit.json"

الإخراج يخفي سياق الحساب ويعرض Hash مقتطعاً. لا تشارك قاعدة SQLite الخام أو كلمات المرور.
