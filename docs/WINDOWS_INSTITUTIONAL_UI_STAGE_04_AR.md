# UI-04 — تحديث الصفحة الحقيقي واستعادة ترتيب مساحة العمل (Windows Slint)

هذه مرحلة تطوير مستقلة فوق UI-03 (#118) وليست إعادة بناء تطبيق ويب. كل تحديث في الواجهة يستدعي callback موجودًا بالفعل في Rust/ Core؛ لا توجد إشارات تداول، أو مؤشرات تعلم، أو قيم حساب اصطناعية.

## المنفذ

- زر «↻ تحديث الصفحة» في رأس المحتوى، يظهر عبر كل الـ22 صفحة لكنه **لا يتفعّل** إلا على 14 صفحة لها مسارات تحديث فعلية: سجل النظام، المخاطر، Backtest، الأخبار، التقييم الزمني، نماذج التعلم، النسخ، مركز التداول، المختبر، وايكوف، التنفيذ، الارتباط، سجل MT5، وغرفة العقول.
- الزر معطّل أثناء أي عملية تحديث متزامنة لمنع الضغط المكرر، ولا يُرسل أمر تداول أو يبدّل الحساب أو يغير المخاطر.
- أصبحت حالة إظهار «جميع الصفحات» تُحفظ بجانب الثيم وطي القائمة في الملف المحلي ui-appearance.json. استعادة الملفات القديمة ذات الحقلين ما زالت مدعومة؛ القيم الخاطئة تُستبدل بالافتراضي.
- اختبارات Rust للتحقق من المظهر السابق واللاحق، واختبارات Python للتحقق من وجود callbacks حقيقية وعدم جعل الواجهة مجرد أزرار زينة.

## لم يثبت بعد

- قبول التشغيل على Windows الحقيقي وربط MT5 Demo، والتفاعل الفعلي بالنقر لجميع الصفحات، وعدم انقطاع الصور على أحجام Windows والأجهزة المختلفة.
- أداء وسلامة التداول في الأسواق الحقيقية لا يستنتجان من فحوص العرض. لا دمج قبل نجاح Linux + Windows + Research على commit النهائي.
