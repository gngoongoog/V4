# UI-03 — توسيع التصميم المؤسسي لصفحات العقول والمخاطرة والتنفيذ في Windows

مبني فوق #116 و#117 على نفس Slint الأصلي، دون تبديل محرك التداول.

## إضافات فعلية

- Breadcrumb واضح بعنوان الصفحة الحالية لكل واحدة من صفحات البرنامج الـ22، من النظرة العامة حتى غرفة العقول؛ يغيّر العنوان حسب رقم الصفحة الحالي ولا يتوقع حساباً أو وضع تداول.
- غرفة العقول: بطاقات حالة تعرض الوضع الحقيقي المختار، نوع حساب الوسيط الفعلي، وتوفر بيانات لوحة العقول من Core، مع Panel مستقل لتعديلات العضوية وتفعيل التدريب الافتراضي. بقيت قائمة العقول، والأزرار Save/Refresh/Freeze/Stop، وشروط تعطيلها أثناء التشغيل، كما كانت. إضافة لوحة تقرير العقل ولوحة إجمالي العقول داخل Cards منسقة بالثيمات الثلاثة. كلمة «متاح» تعني فقط وجود بيانات مراقبة، لا أن العقل رابح أو تعلّم بنسبة معينة.
- تنفيذ MT5: ثلاث بطاقات أول الصفحة للاتصال وحالة التنفيذ والقرار الحالي، تعتمد على `exec-busy` و`execution-active` و`account-mode-label` و`decision` الواردة من النظام.
- صفحة المخاطرة: Equity، نوع الحساب، حالة التنفيذ، وحالة تحديث تدقيق القاطع، بالإضافة إلى Card لتقرير Core الحقيقي. تبقى جميع حقول المخاطرة قابلة للتحرير مع نفس شروط الحفظ أثناء STOP؛ القاطع ومخاطرة الحساب الحقيقي لا تتغير تلقائياً من واجهة العرض.
- اختبارات Python تؤكد أن كل 22 صفحة لها عنوان، وأن الصفحات الحرجة تستخدم قيم Core الفعلية، وأن callbacks الخاصة بحفظ عضوية العقول وربط الحساب وحفظ المخاطرة باقية.

- لتحسين توزيع المساحة مثل تصميم المرجع، قُلّص شريط الأقسام القديم افتراضياً وأُضيف زر «جميع الصفحات» لإظهاره عند الحاجة. قائمة اختيار واحدة في شريط عنوان الصفحة توفر **جميع الـ22 صفحة** وتشغّل تحديث الصفحة المختارة عند الانتقال إلى صفحات المخاطرة والعقول والتنفيذ والأخبار البحثية/التقييم حيث يلزم. لم تُحذف أزرار الأقسام القديمة أو callbacksها.

## حدود القبول

هذه المرحلة تغطي إعادة عرض وحماية نقاط التحكم الأساسية، لكنها **ليست إعادة تصميم نهائية لكافة 22 صفحة** حتى تتطابق Pixel-by-pixel مع الصورة. باقي الصفحات ما زالت تعتمد عناصر Slint الأساسية التي تحتاج تحسين توزيع المساحات. كذلك لا نستطيع إعلان نجاح كامل قبل Test على Windows x64 في بيئة مستخدم مع بيانات MT5 Demo وسجل تشغيل، وفحوص CI على SHA نهائي.

لا تحتوي هذه المرحلة على أرقام تعلّم اصطناعية ولا إعداد LIVE سريع يخالف تأكيد الحساب. يجب ألا يُدمج PR قبل نجاح Windows/Research/Linux وبعد المراحل الأساسية السابقة.
