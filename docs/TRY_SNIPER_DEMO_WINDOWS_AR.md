# دليل تجربة BrainTrade OS V4 على Windows — القناص المتعلّم

**نوع النسخة:** Development Preview 0.7 — للاختبار على حساب **MT5 Demo**. ليست نسخة موثقة للربحية أو للاستخدام المباشر برأس مال حقيقي.  
**المتطلبات:** Windows 10/11 بنظام 64-bit، برنامج MetaTrader 5 الخاص بوسيطك، حساب Demo، اتصال إنترنت، ومساحة لفك ضغط ZIP كاملاً. حزمة BrainTrade تضم Python اللازم للتشغيل؛ لا تحتاج تثبيت Rust أو Python بشكل منفصل.

## 1. فك الضغط وتشغيل البرنامج

1. نزّل ملف `BrainTrade-Windows-x64-v0.7.1-Preview.zip` من قسم **Artifacts** في تشغيل GitHub Actions الناجح للمشروع. في الغالب يعطي GitHub ملف ZIP خارجياً يحتوي ZIP الحزمة نفسها؛ فك الخارجي أولاً إن لزم.
2. فك ضغط **الحزمة الداخلية كاملة** إلى `C:\BrainTrade-V4-Demo\` (مثلاً). لا تشغّل `BrainTrade.exe` من داخل ZIP ولا تنقل EXE وحده خارج مجلده.
3. أغلق أي نسخة BrainTrade قديمة باستعمال زر **خروج كامل**. اترك MT5 مفتوحاً أو اسمح للبرنامج بتشغيله.
4. شغّل `BrainTrade.exe` من المجلد. سيبدأ في وضع **STOPPED**. لا يعني فتح الواجهة السماح بفتح صفقات.

## 2. ربط حساب MT5 التجريبي

1. افتح MetaTrader 5 وسجّل دخول حساب **Demo**. تأكد من أنك تستطيع قراءة سعر الذهب، وأن السوق والرمز يسمحان بالتداول.
2. في BrainTrade افتح **النظام ← MT5 / Telegram** واختر مسار `terminal64.exe` الخاص ببرنامج وسيطك.
3. ضع اسم الذهب **كما يظهر حرفياً في MT5**: `XAUUSD` أو `XAUUSDm` أو أي لاحقة فعلية لوسيطك. احفظ الإعدادات وأعد الاتصال.
4. انتظر حتى تظهر هوية الحساب ونوعه والرصيد والسعر. لا تستخدم بيانات افتراضية ولا تربط حساب Live لهذه التجربة.
5. افتح **التداول ← التنفيذ**، اختر `Demo` واربط **الحساب الحالي**. راجع Login/Server والعملة والرمز. إذا تغيّر الحساب، أعد الربط من جديد.

## 3. ضبط القناص — ثابت أو يتعلّم أهداف الربح

1. افتح **التداول ← الوضع والتكلفة** واختر `Sniper / القناص`.
2. اختر `القناص المتعلّم / Sniper Learner`. هذا الاختيار لا يشغّل أمر تداول وحده.
3. **نقاط / pip**: عيّن التحويل وفق `point` وعدد المنازل العشرية في مواصفات رمز الذهب لدى وسيطك. `pip` في XAUUSD ليس موحداً عند جميع الوسطاء. مثال: إذا اعتبرت 10 نقاط = pip واحد، فالهدف الثابت 5 pip يعني 50 point.
4. **الهدف الثابت (pip)**: أدخل مثالاً `5`.  
   **هدف متعلّم داخل نطاق — Demo فقط**: اختر هذا الخيار واضبط مثلاً **أدنى 3 pip، أعلى 9 pip**. يستخدم القناص أربعة أهداف داخل حدودك، ويسجل الهدف المختار عند الدخول.
5. اضبط **الوقف بالنقاط**، و**مدة الاحتفاظ القصوى بالثواني**، و**فاصل إعادة الدخول**؛ ابدأ بقيم متحفظة وفق تحمل المخاطرة ولا تزد اللوت لغرض زيادة عدد الصفقات.
6. أدخل عمولة الوسيط لوت واحد: اختر **لكل جهة** إن كانت العمولة محسوبة على الفتح والإغلاق منفصلين، أو **ذهاب وإياب** إن كان المبلغ كلياً. راجع حاسبة **السبريد والعمولة والانزلاق** على السعر الحالي. الهدف يجب أن يكون معقولاً بعد التكلفة.
7. اضغط **حفظ إعدادات التداول** قبل البدء. النظام يتحقق من صحة الحدود ويرفض التغيير أثناء التشغيل.

## 4. اللوت وطريقة تنفيذ القناص

- الأسهل: من **التداول ← التنفيذ** اختر العقل `النظام — الوضع المختار`، اضبط اللوت المناسب للديمو واترك القناص المتعلّم ضمن منسّق النظام. لا تحتاج تشغيل القناص كـ SOLO.
- الاختبار المتقدم: اختر `القناص المتعلّم — اندفاع وارتداد سريع` في صفحة العقول، واضبط لوتاً مستقلاً واختر تشغيله **منفرداً SOLO** إذا كنت تريد فصل ملكية صفقاته. لا تشغّل المنسّق وSOLO لنفس إشارة القناص معاً. يسمح النظام بالعودة بعد مصالحة أوامر القناص ومراكزه.
- إذا كان رصيد Demo صغيراً، تحقق من **الحد الأدنى لحجم العقد ومتطلبات الهامش** للذهب لدى وسيطك. قد لا يكون 0.01 لوت قابلاً للتنفيذ على حساب 100 دولار. لا يجوز تجاوز حدّ الوسيط أو تقديم ضمان بإمكانية فتح الصفقة.
- اضغط **START** فقط بعد التحقق من الحساب/الرمز/التكاليف. زر **STOP** يمنع فتح مراكز جديدة؛ وقد تستمر إدارة الصفقات المملوكة أو تبقى المراكز مفتوحة لدى MT5 وفق الحالة. **خروج كامل** لا يغلق مراكز الوسيط تلقائياً.

## 5. التأكد أنه يفتح ويتعلم فعلاً

1. شغّل النظام خلال ساعات تداول الذهب، مع اتصال MT5 واستقبال أسعار حديثة. القناص يحتاج عدة تحديثات أسعار منفصلة قبل تكوين إشارة؛ عدم فتح صفقة خلال دقائق ليس وحده دليلاً على عطل.
2. في **التداول ← التنفيذ** راجع **سبب WAIT / READY، الأمر، الرد من MT5، عمولة الحساب، الاختيار الحالي للهدف بالـpip**. لا يُعد الأمر صفقة مكتملة لمجرد أنه في قائمة الطلبات؛ تحقق من التذكرة والتنفيذ لدى MT5.
3. افتح **التداول ← تقدّم التعلّم**، وتابع الصفقات **المغلقة بالكامل**، وربح/خسارة MT5 الصافي بعد `profit + commission + swap + fee`. الإغلاق الجزئي لا يدرّب أوزان الهدف.
4. لكل هدف pip سجل عيّناته ومكافأته؛ لا تتعامل مع رقم `exploration_rate` باعتباره احتمالية ربح، ولا تعتمد أفضل هدف دون عينات جديدة كافية.
5. في وضع هدف pip المتعلّم، إذا عدّل الوسيط TP المرسَل عن المطلوب، يحتفظ النظام بسجل النتيجة الواقعية لكنه لا يحتسبها عينة صحيحة لمقارنة أهداف الـpip.
6. لإثبات تحسن التعلم، لا تعتمد على أول عشر صفقات. اجمع نتائج عبر جلسات مختلفة، وراقب **صافي الربح بعد التكلفة، عدد الصفقات، أقصى تراجع، أخطاء الإرسال، ونتائج الصفقات الجديدة**. الربح غير مضمون.

## 6. إجراء فحص قبول شامل على جهازك

شغّل `Run-Demo-Acceptance.cmd` من المجلد الرئيسي بعد ربط Demo وتجهيز Fast Pulse. هذا يفتح واجهة فحص **قراءة وتسجيل فقط**؛ لا يرسل صفقات ولا يبدأ/يوقف التداول من تلقاء نفسه. يسجل مثلاً زمن الطابور والتنفيذ ومصادر `native` أو `poll` ويولد الملفات داخل `acceptance-output`.

للمقارنة بين Native OnTick وPoll:
- `native`: اختبر بعد تركيب `MT5\Experts\BrainTradeSniperBridge.mq5` في MetaEditor وترجمته وربطه بمخطط الذهب، مع نجاح اتصال الجسر.
- `poll`: اختبر بجلسة مستقلة عند إيقاف جسر Native مع تفعيل مسار Poll الاحتياطي.
- تذكّر أن تجميع عينة latency صغيرة لا يثبت دقة التنفيذ في السوق، وقارن ظروف الجلسات والتكاليف.

## 7. إذا لم يفتح صفقات أو ظهرت مشكلة

افحص بالترتيب: `START/STOP`، حساب Demo المطابق، `Trade allowed` في MT5، اسم الرمز، صلاحية الأسعار، السبريد والعمولة مقابل الهدف، اللوت/الهامش، حالة الطلب السابق `unknown/placed/partial`، وجود مركز مملوك، وبوابة MT5. لا تعالج الأمر بمسح قاعدة البيانات أو إرسال الأمر نفسه يدوياً عدة مرات؛ حالة التنفيذ غير المؤكدة تُصالَح أولاً.

لإرسال تقرير تشخيص: افتح **تقدّم التعلّم** و**التنفيذ**، احتفظ برسالة الخطأ ووقت حدوثها وسبب WAIT، ونتائج `Run-Demo-Acceptance.cmd`. **احذف بيانات الحساب الشخصية وأي كلمات مرور أو مفاتيح سرية قبل مشاركة التقارير**.

## 8. الحفاظ على تدريبك عند تحديث النسخة

من **النظام ← النسخ** أنشئ نسخة احتياطية قبل التحديث، واضغط **خروج كامل**، ثم ضع النسخة الجديدة في مجلد منفصل. بيانات التعلم والمذكرات توجد في مجلد بيانات التطبيق للمستخدم، وليست داخل `BrainTrade.exe`. لا تحذفها لإصلاح مشكلة دون نسخة. تغيّر إعدادات القناص قد ينتج تعريف تجربة جديداً، ولكنه لا يمسح سجل صفقات الوسيط السابق.

---

**حدود التحقق:** نجاح اختبار GitHub Windows وLinux والمحاكي يثبت صحة سيناريوهات الاختبار فقط، وليس كل حسابات الوسطاء. لا يمكن إقرار نجاح تجربة MT5 Native الحقيقية قبل تشغيل هذه الحزمة على جهازك وجمع تقرير القبول. لا تنتقل لحساب Live بناءً على النتائج الأولية.
