# BrainTrade OS 0.4.0 Preview — تقرير التسليم

اعتمدنا V4 / development لأنه يحتوي جميع مسارات BrainTrade-OS ومكونات بحث إضافية. بقي المستودع الآخر محفوظاً. المقارنة في Source/docs/REPOSITORY_COMPARISON.md.

## ما تتضمنه النسخة

- تشغيل من BrainTrade.exe واحد، مع Core وPython وجسر MT5 مضمّنين؛ يبقى تثبيت MT5 وتسجيل حسابك فيه مطلوباً.
- 14 صفحة للحساب والإعدادات والسجل والعقول والفرص وخريطة السوق والمحاكاة والمخاطرة والاختبار التاريخي والتقييم والتعلم والأخبار والنسخ والاستعادة ومعلومات التطبيق.
- عقول الاتجاه والحالة السوقية والهيكل والتذبذب ومناطق الطلب والعرض والدعم والمقاومة والقمم والقيعان والزخم والتباعد، ونماذج الارتداد والاختراق وإعادة الاختبار مع Entry/SL/TP عندما تكتمل الشروط.
- Gann وعمق السوق المتاح من الوسيط وسياق أخبار Fed/ECB. نشاط ticks لا يُعرض كحجم عالمي، ولا تُختلق بيانات مفقودة.
- Meta v1/v2 وCES وKTE للاختبار التاريخي، إعادة تشغيل محفوظة ومقارنات بنفس البيانات وتقارير شموع وتقييم زمني.
- مسار التعلم من عينات الشموع المكتملة إلى النتائج المؤجلة والتصدير والتدريب الخارجي واستيراد النموذج والتوقعات البحثية وقياسها ومراجعات الأداء المحفوظة.
- نسخ واستعادة عبر الواجهة مع فحص النسخة ونسخة تراجع وإعادة تشغيل وعرض النتيجة. الأسرار المحلية لا تدخل النسخ.

## أهم الإصلاحات والتحقق

سُحبت خطط الدخول القديمة عند STOP أو فقد حداثة البيانات، وصُحح تحديث التحليل عند تصحيح تاريخ الشموع. تحسنت إعادة اشتراك عمق السوق وتجميعه. مُنعت توقعات النموذج داخل فترات بيانات تدريبه واختباره. صارت مراجعة الأداء مرتبطة بهوية النموذج والدليل المعروض. فحص النسخ لا يحذف ملفات جانبية غير متوقعة.

نجح 88 اختبار Rust و32 اختبار Python، وفحص تكامل المحرك وتقارير البحث والاستعادة. نجح بناء ويندوز وفحص الحزمة الفعلية: بدء Core، اتصال DPAPI، استعادة وإعادة تشغيل، حفظ مفتاح الاتصال، ورسم 14 صفحة بحجمين مع التحقق من اكتمال 28 صورة. اختبار شبكة حية واحد متجاهَل ومنفصل عن هذه النتائج. التفاصيل في Source/BUILD_HANDOFF.md وSource/docs/validation.json.

## ما بقي

هذه نسخة تحليل وبحث ومحاكاة Shadow؛ لا تفتح أو تعدل أو تغلق صفقات الوسيط. Legacy Meta يقود المحاكاة، والعقول والنماذج الأخرى للتحليل والقياس البحثي. لا يوجد Champion تلقائي. تنفيذ أوامر الوسيط وتسويتها ومخاطر المحفظة تحتاج مرحلة مستقلة.

بقيت التجربة على لابتوبك مع MT5 الخاص بوسيطك وتاريخه وDOM وTelegram بإعداداتك الفعلية. نجاح الاختبارات لا يثبت الربحية. لا توجد بيانات حساب حقيقية مضمّنة بالحزمة.

للبدء اتبع README_AR.md بجانب التطبيق. شفرة المشروع الكاملة داخل Source.
