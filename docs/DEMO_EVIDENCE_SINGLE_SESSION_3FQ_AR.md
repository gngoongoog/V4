# المرحلة 3F-Q — حزمة أدلة MT5 Demo في جلسة واحدة

الأداة `gateway/demo_evidence_bundle.py` تشغل **ثلاث مراحل للقراءة فقط** بضغطة واحدة بدلاً من تنزيل ملفات متفرقة:

- 3F-M: قراءة سجل الصفقات في حساب Demo المحلي عبر `history_deals_get`، من دون إكمال تاريخ غير موجود أو تخمين رقم العقل/الصفقة.
- 3F-N: قراءة Bid/Ask التاريخية قبل الصفقات من نفس حساب Demo، مع شرط عمر السعر المرجعي.
- 3F-O: مقارنة الملفين حسب أرقام صفقات الوسيط والأحجام والأسعار والعمولات وإظهار الحالات المتعارضة.

كل هذا يحدث عند تشغيل الأمر **يدوياً**. لا يوجد تشغيل تلقائي في الخلفية، ولا تعديلات على إعدادات مخاطرة BRAINTRADE، ولا أوامر `order_send` أو `order_check` أو اتصال بالداشبورد.

## تشغيل مباشر على Windows

افتح MT5 على حساب **Demo فقط**، وتأكد من توفر Python وحزمة MetaTrader5 ومن وجود رمز الذهب الصحيح لدى وسيطك. داخل مجلد المشروع:

```powershell
python gateway/demo_evidence_bundle.py --symbol XAUUSD --hours 2 --output demo_bundle.json
```

اختيار `--hours` من 1 إلى 24، والإعداد الافتراضي ساعتان. للأصل إذا الوسيط يسمي الذهب `XAUUSDm` اكتب رمز الوسيط نفسه. إذا تريد ربط رقم مركز الوسيط بـ ID خاص بمحاكاتك، وفّر ملف JSON تعيين معتمد منك:

```powershell
python gateway/demo_evidence_bundle.py --symbol XAUUSD --hours 2 --map-position-ids positions.json --output demo_bundle.json
```

إذا غاب هذا الملف، تُترك `intent_id` مجهولة، ولا تخمن الأداة الربط من السعر أو الوقت.

## التدقيق بعد حفظ الملف

```powershell
python gateway/demo_evidence_bundle.py --verify demo_bundle.json
```

وضع `--verify` يعمل **بدون فتح MT5 وبدون اتصال بالوسيط**؛ يعيد فحص بصمات SHA-256 لكل جزء، ثم يعيد حساب مقارنة السجلات من الصفر. التخزين المحلي يتم بإنشاء ملف جديد بصورة ذرّية قدر الإمكان، ولا يكتب فوق ملف سابق. الملفات تحتوي هوية حساب Demo وصفقاته، فاحتفظ بها محلياً بشكل خاص.

## تفسير الحالة

- `descriptive_sample_unverified`: البيانات المحلية متطابقة فيما بينها وبها 30 صفقة ذات أسعار مرجعية أو أكثر. **ليست شهادة من الوسيط**.
- `insufficient_or_sparse_reference`: عينة قليلة، أسعار غير متوفرة أو سجلات ناقصة.
- `contradictory_exported_records`: اختلاف في رقم صفقة أو الحجم أو السعر أو عمولة أو توقيت أو معلومات أخرى بين المصدرين.

الـ SHA-256 يكتشف التعديل على الملفات بعد حفظها، لكنه **لا يثبت أن البيانات جاءت فعلاً من الوسيط**، ولا يمنع شخصاً من صنع ملفات مزيفة وإعادة حساب البصمة. كل التقارير تذكر أن بيانات الحساب وسجل الصفقات غير موثقة رسمياً وأن اكتمال التاريخ غير مثبت.

## حدود معروفة

الدوال المستخدمة مستقلة عن محرك التداول الحقيقي. قد تتغير سجلات الوسيط بين قراءتي السجل، وقد تتأخر الأسعار التاريخية، وقد يحتاج المركز إلى مراجعة `INOUT` أو `OUT_BY` في حسابات Netting وHedging. إن تغير الحساب أثناء أي قراءة أو غابت بيانات ضرورية تتوقف العملية، ولا تُستنتج أرباح حقيقية من المحاكاة. لا تستعمل نتيجة هذا التقرير للسماح بالتداول الحقيقي أو لتعطيل قاطع الخسارة.

تشمل الاختبارات حالات حساب Demo وحساب REAL، ومطالبة الحساب المتغيرة بين القراءتين، ونقص السجلات، والملفات المعدّلة، وعدم الكتابة فوق تقرير سابق، وعدم إرسال صفقات.
