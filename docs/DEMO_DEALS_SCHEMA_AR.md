# صيغة بيانات دراسة الأوضاع الأربعة

الدليل البحثي يجب أن يأتي من **تاريخ إغلاق صفقات MT5 Demo عند الوسيط**، وليس قيم الشموع الافتراضية أو أرباح Backtest. يحتاج البرنامج مصفوفة JSON من السجلات. المثال التالي **تعليمي افتراضي فقط** وليس صفقة حقيقية:

```json
[
  {
    "deal_ticket": 111111,
    "closed_ms": 1700000000000,
    "mode": "sniper",
    "symbol": "XAUUSD",
    "login": 123456,
    "server": "Broker-Demo",
    "target": "demo",
    "profit": 1.30,
    "commission": -0.70,
    "swap": 0.0,
    "fee": 0.0
  }
]
```

`mode` واحدة من `sniper`,`scalping`,`swing`,`expert`. `closed_ms` مللي ثانية UTC وقت الإغلاق. يجب أن تكون `deal_ticket` أرقام صفقات MT5 فريدة. يجب أن يكون إسناد الوضع للصفقة معتمداً على سجل أوامر V4؛ هذا الملف وحده لا يثبت الإسناد. تُرفض الحسابات المختلطة وبيانات REAL والمكونات الناقصة. لا تتعامل مع نتيجة Bootstrap كنسبة ضمان لنجاح صفقة مستقبلية. لا تحدث ترقية تلقائية للأدمغة.
