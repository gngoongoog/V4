# UI-05 — تجاوب واجهة Windows وإصلاح إيقاف المختبر

## إصلاح وظيفي: زر إيقاف وإلغاء المختبر

في النسخة السابقة كان الزر معطلاً عند studio-busy، وكان معالج Rust يتجاهل كل الأوامر عندما تكون المهمة مشغولة؛ لذلك قد لا يمكن إيقاف بحث جارٍ. الآن:
- زر الإلغاء مستقل عن busy الخاص بالمهمة، وله حالة خاصة تمنع التكرار.
- طلب /v1/studio/cancel يُرسل من عامل مستقل كي لا ينتظر طابور عملية تشغيل سابقة.
- الواجهة تعرض نتيجة مؤكدة أو خطأ صريحاً، بدون اختلاق حالة النجاح.
- نفس واجهة Slint القديمة ومسارات Core؛ لا تغيير في أوامر MT5 أو مخاطرة الحساب.

## عرض صغير والثيم الأبيض

- عند تصغير النافذة، تُخفى تدريجياً خانات DAILY NET وBALANCE وEQUITY من **الشريط العلوي فقط** عند حدود 1400/1250/1100؛ لا تُحذف البيانات من Core ولا من صفحاتها.
- شريط وضع التنفيذ أصبح فاتحاً ومقروءاً عند اختيار الثيم الأبيض.
- تخفيف ازدحام الشريط عند 960–1120 px مع الحفاظ على بيانات الحساب ووضعه وأزرار الثيم.

## التحقق المطلوب

- اختبارات Python/Rust وWindows build وResearch native render على رأس الفرع النهائي.
- اختبار نقر واقعي لزر Cancel أثناء تنفيذ Studio، ومعاينة شاشة Windows بأحجام 960 و1120 و1540.
- التحقق من اتصال MT5 Demo وتزامن إغلاق الطلب، ولا يمكن من فحص المصدر وحده ضمان تطابق بكسلي مع الصورة المرجعية أو نجاح الوسيط.
